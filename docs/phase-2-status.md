## 待補與限制

- 真實優惠券由使用者提供，目前沒有可出示的券圖；範例入口不可作為折扣憑證。
- 商家、平台費率、公共 Wi-Fi、VJW 與現金機台支援範圍尚未獨立核對官方資料；JSON 的 `officialVerifiedAt` 保持 `null`。列出官方連結不代表已查證，LUMINE／NEWoMan 數字也仍待原始資料確認。
- 瀏覽器測試使用 Chromium 手機及桌面尺寸，未當作真實 iPhone Safari／加入主畫面 PWA 模式驗收；這些仍需階段 4 與實機確認。
- 本階段不改 Supabase SQL、Auth 或帳本；沒有重新執行資料庫 migration。實際雙手機雲端帳務的既有使用者驗收紀錄屬階段 1。
- Vite 仍提示主要 JS 超過 500 kB（gzip 約 178 kB），建置成功；未隱藏警告。完整載入最佳化保留階段 3／4 評估。
