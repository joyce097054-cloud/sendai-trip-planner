## 已完成

- 提供名稱「仙台手帳」、standalone manifest、自製暖白楓葉圖示（192／512px、maskable 512px、Apple 180px）及 iPhone 設定。
- 建置生成限定靜態檔案清單與內容版本。首次下載完成後可離線重新開啟行程、清單與四張教學原圖；不快取 Auth、雲端帳務、天氣 API 或私人連結參數。
- 加入下載狀態、快取修復、離線提示及使用者確認後的版本更新；下載失敗保留舊版，更新不清除旅記／照片、不強制中斷表單。
- 單檔版保持內嵌資源，明確停用網路版 worker。沒有新增依賴。
- 部署準備指令與實際發布分開。發布需 `--publish`、乾淨提交、公開 client 設定與既有 App 標記；產物包含來源提交、PWA 版本及公開設定是否就緒的布林值，不包含私人連結或個人資料。
- 提供 [iPhone 使用、更新、部署與實機驗收步驟](pwa-and-deployment.md)。
