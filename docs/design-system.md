# 介面設計系統

更新：2026/11/06（台灣時間）。階段 3 沿用原 React／TypeScript 專案，將樣式分為可維護的共用規則與頁面規則，不新增 UI 套件。

## 色彩與文字

設計方向為日式旅行手帳與生活風格雜誌。以日期、字級、線條及留白建立層次；橘色用於選取、導航與主要操作，內容不套用大面積橘色或漸層。

| 用途 | Token | 色碼 |
| --- | --- | --- |
| 暖白紙面 | `--paper` | `#FAF8F4` |
| 表單／對話框 | `--card` | `#FFFFFF` |
| 主要文字 | `--ink` | `#493B32` |
| 輔助基色 | `--ink-secondary` | `#87796E` |
| 小字與長篇輔助文字 | `--muted` | `#75685E` |
| 強調與選取線 | `--accent` | `#C97645` |
| 可操作文字／主要按鈕 | `--action` | `#9C512B` |
| 分隔線 | `--line` | `#E8E1D9` |
| 補充底色 | `--wash` | `#F2EDE6` |
| 完成／同步正向狀態 | `--sage` | `#59684F` |

指定的橘色與輔助基色保留於色票，細字使用較深的對應色，改善戶外閱讀。依 WCAG 相對亮度公式，主要文字對紙面約 10.13:1、輔助文字約 5.08:1、主要按鈕白字對底色約 5.79:1；數值描述這些色組，不代表所有頁面已完成完整無障礙審查。

字體依序使用 Zen Maru Gothic、Noto Sans TC、Noto Sans JP、蘋方、微軟正黑體與系統字體，不依賴外部字型請求。日期及大金額適度使用 Georgia 數字，中文不混用多套展示字體。

| 層級 | 基準 |
| --- | --- |
| 一般文字／輸入內容 | 16px，行高 1.8 |
| 長篇補充與標籤 | 14px，行高約 1.9 |
| 資料時間／短標記 | 12px，特殊短標記最小 11px |
| 區段標題 | 20–26px，字重 600 |
| 日期／結算金額 | 46–64px，依螢幕調整 |

## 間距、容器與互動

- 共用間距為 4、8、12、16、24、32、48px；手機外距 18px，桌面內容最大寬 1100px。
- 一般控制項圓角 6px；表單與對話框 12px。時間軸、手冊與帳務列表多用細線分隔，避免每段都是同尺寸卡片。
- 按鈕與圖示操作至少 44 × 44px，主要手機操作為 48px 高。勾選圓圈雖較小，外層實際按鈕仍為 44px。
- 所有文字輸入保持至少 16px，降低 iPhone Safari 聚焦時自動縮放的機率。必要欄位、錯誤、停用與等待狀態沿用原驗證機制。
- 鍵盤焦點使用明確外框；對話框使用原生 `dialog`、Escape 關閉與焦點歸還。依 `visualViewport` 更新可用高度，內容可捲動，儲存操作可留在可見區域。
- 頁面切換僅短淡入；`prefers-reduced-motion` 停用動畫及平滑捲動。沒有裝飾性循環動畫或發光。
- 底部導覽為全寬平面列：行程／指南／天氣／分帳。以細線、文字與圖示顯示選取，採 `env(safe-area-inset-bottom)` 留空；頁面底部有額外空間。
- 次頁使用較短的旅行頁首，日期與倒數保留；各頁記住本次開啟期間的捲動位置，購物分類及天氣地點也在分頁間保留。這些是介面狀態，不改寫共同帳務。

## 四頁排版

- 行程：大日期與地區、平面垂直時間軸、固定日期切換；交通／景點資訊可收合，地圖與完成勾選直接可用。景點若有個人照片，就顯示該照片，不放假景點照片。
- 指南：桌面側邊目錄、手機橫向章節導覽，含清單、交通景點、優惠券、免稅、旅行資料、注意事項與緊急資訊。四張教學原圖與來源狀態保留。
- 天氣：目前模式溫度作為主資訊，五日預報改成易掃讀的列表；體感、日出日落與穿搭可展開。即時模式、最近資料、預報及未取得各自標示。
- 分帳：頁首先提供新增消費，主要區域顯示結算對象及金額；兩人的實付與負擔直接可見，私人連結設定移至後方。使用原有純計算、雲端存取與衝突處理。

## 程式位置

`src/styles.css` 統一匯入以下樣式：

| 檔案 | 職責 |
| --- | --- |
| `src/styles/tokens.css` | 色彩、字體、字級、間距、圓角 |
| `src/styles/base.css` | 標題、按鈕、表單、焦點、對話框、狀態 |
| `src/styles/layout.css` | 頁首、版寬、導覽、通知、轉場 |
| `src/styles/itinerary.css` | 日期、時間軸、旅記與照片 |
| `src/styles/guide.css` | 手冊、清單、券圖、教學與費用資料 |
| `src/styles/weather.css` | 目前天氣、預報列表及穿搭 |
| `src/styles/ledger.css` | 結算、帳務列表、表單呈現 |

共用元件為 `components/ui/PageHeading.tsx`、`TripHeader.tsx`、`Modal.tsx`；指南目錄位於 `components/guide/SectionIndex.tsx`，時間軸行程位於 `components/ItineraryStop.tsx`。設計規則一致，各頁仍保有不同的資訊編排。

真實 iPhone Safari 與主畫面 PWA 模式仍需階段 4 實機驗收。Chromium 手機尺寸、縮小高度及 CSS Safe Area 規則不代表已完成實機測試。
