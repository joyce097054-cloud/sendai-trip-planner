# 階段 3：設計系統與四頁優化交付

更新：2026/11/06（台灣時間）。使用者已確認階段 2 並授權本階段；本階段沒有部署、不執行 SQL，也沒有開始階段 4。

## 完成的調整

- 建立可維護的色彩、文字、間距、按鈕、表單、焦點與對話框規則，拆分共用及各頁 CSS。主要文字與操作使用足夠對比的深棕／橘棕，保留指定低飽和色票。
- 次頁縮短旅行頁首，保留名稱、日期及倒數；手機行程頁省去大幅裝飾插畫，桌面仍保留原插畫。四頁導覽改為貼齊螢幕的平面列，考慮 Safe Area 與內容底部留白。
- 行程以大日期、地區與平面垂直時間軸呈現；日期列可固定於上方，選日後定位到該日。交通／景點內容可展開，地圖、步行及完成勾選直接可用。個人景點照片可作為預覽，不建立假景點圖。
- 指南改為旅行手冊編排，桌面側邊目錄、手機橫向章節目錄，保留清單、交通景點、旅行資料、注意事項、緊急資訊、優惠券、退稅原文、21 筆費用及四張使用者原圖。
- 天氣使用 API 的 `current` 模式資料呈現目前溫度、體感、狀態及資料時間；不以每日高溫冒充目前溫度。30 分鐘內且未異常超前的模式資料標示「即時・模式估計」，較舊資料標示「最近資料・非即時」，缺資料則明示。
- 五日預報改為高低溫／降雨的列表，體感、日出日落及穿搭可展開；季節性參考與預報分開。網路及格式錯誤以繁體中文提示，不填造數據。
- 分帳頁首可直接新增消費，主要資訊為結算對象與金額；兩人的實際付款／負擔直接可見，私人連結設定移至紀錄之後。原有平均、單人、自訂、匯率、部分結算與 CSV 保留。
- 每頁保留本次開啟期間的捲動位置，清單分類與天氣地點可在切頁後保留。主要觸控區至少 44px，輸入內容至少 16px，減少 iPhone 聚焦縮放。
- 共用原生對話框依 `visualViewport` 更新可用高度，可捲動並保持儲存操作可達；支援 Escape、焦點歸還與鍵盤跳至主要內容。動畫輕量且支援減少動態效果。

詳細規則與檔案對應見 [設計系統](design-system.md)。沒有新增依賴。
