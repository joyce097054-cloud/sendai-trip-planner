# 階段 1 狀態：私人連結雙人分帳

日期：2026/11/05（台灣）。使用者已確認原本機資料備份；此次將先前 Email 會員設計改為私人連結＋背景匿名驗證。只執行階段 1，未進入指南擴充、全面設計、PWA 或新版部署。

## 已實作

- 沒有 Email／密碼／驗證信／OTP／SMTP 或個人會員畫面。
- 同一 256-bit 私人連結可開啟同一本 Supabase 帳本；裝置匿名身分數量不限制為兩個。
- 兩位固定帳務參與者使用獨立 UUID，與裝置 UID 分開；付款人明確選擇名字，不將建立者或手機預設為 A／B。
- PostgreSQL 為共同帳務唯一權威來源；背景匿名 session 與私人連結快取不作為帳本資料庫。
- 每筆消費獨立 ID、整數日圓、奇數平均由付款人負擔、單人／自訂分攤、decimal 匯率、台幣估算、部分結算及 BOM CSV。
- RLS 及受控 RPC、連結雜湊、冪等請求、版本衝突、離線阻擋、重連／前景重新抓取。
- 私人連結可輪替，撤銷舊連結及其他裝置授權；原有帳目保留。
- 新增 002 migration，沒有變動或刪除 001／舊會員資料；新專案只執行 002 即可。SQL 管理者可選擇複製已有兩名成員的舊帳本，原資料不動且不重複匯入。

PostgreSQL 測試只在 localhost 隔離資料庫執行，Auth UID 契約由測試 harness 提供；瀏覽器使用明確的測試用 Auth／WebSocket 回應。這些結果**不等於**正式 Supabase Anonymous Auth／Realtime 或兩支真實 iPhone 已驗收。
