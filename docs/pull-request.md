# 仙台旅行手帳：私人雙人分帳、指南與手機 PWA

將原本機旅行手帳擴充為兩支手機以私人連結共用的 Supabase 帳本，無 Email／密碼介面。固定兩位帳務參與者與裝置身分分離，保留整數日圓、付款人承擔奇數餘額、單人／自訂分攤、decimal 匯率、部分結算及 CSV。交易式 RPC、RLS、版本檢查與冪等請求處理同步、舊表單衝突及失敗重送；舊會員資料保留。

指南新增 App 內優惠券檢視、四張使用者原圖、獨立退稅資料與 21 筆商家費用。四頁改為一致的日式旅行手冊排版，保留原行程、清單、照片與 v1 JSON。PWA 提供專案圖示、限定靜態內容的離線重新開啟、下載狀態及手動更新；共同帳務與天氣保持連線使用。部署準備與實際發布分開，尚未更新測試站。

驗證：TypeScript、正式建置、43 項單元測試、58 項 Chromium 瀏覽器檢查通過（原互動 33、分帳合約 10、正式子路徑 8、單檔 1、原生 worker 6；另 1 項手機專用測試在桌面略過）。既有資料與四張原圖校驗一致。網路 API 使用明確測試回應，不能代替真實 Supabase 與 iPhone Safari／主畫面實機驗收。

部署及待測矩陣見 `docs/pwa-and-deployment.md`；結果及限制見 `docs/phase-4-status.md`。真實券圖、部分退稅官方查核、實機完整矩陣與本版發布尚未完成。
